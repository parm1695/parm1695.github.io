Privacy Policy

Last updated: September 2026

YT Auto ("the App") is a personal automation tool operated by its sole developer for use on the developer's own YouTube channel.

Information accessed

The App uses the YouTube Data API to (a) upload videos to the owner's channel and (b) read public statistics (views, likes, comments) of videos on the owner's channel. Access is granted via Google OAuth by the channel owner only.

Data storage and sharing

OAuth tokens are stored as encrypted secrets in a private GitHub repository owned by the developer. No personal data of any other user is collected, stored, sold or shared with third parties. The App does not use cookies and does not track visitors to this website.

Google API Services

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
