YT Auto

YT Auto is a personal, single-user automation tool that creates short educational videos and uploads them to the owner's own YouTube channel on a schedule.

What it does

  • Generates a short script on a topic using an AI language model
  • Creates a voiceover and combines it with licensed stock footage
  • Uploads the finished video to the owner's YouTube channel using the YouTube Data API
  • Reads the owner's own video statistics to improve future videos

Who uses it

This tool is used only by its developer on their own YouTube channel. It is not offered to the public and does not collect data from any other users.
